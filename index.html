Mengintegrasikan data cuaca laut dari BMKG dan data AIS untuk fitur monitoring. Mengembangkan dashboard monitoring dengan visualisasi data dalam bentuk grafik serta fitur jadwal angkutan penyeberangan. Menerapkan metode Fuzzy Logic Mamdani menggunakan parameter tinggi gelombang, kecepatan angin, dan kecepatan arus untuk menentukan tingkat keselamatan pelayaran.
